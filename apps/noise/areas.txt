# Which areas get noise tiles.
#
#   docker compose -f docker-compose.prod.yml run --rm builder \
#     build-noise-tiles --areas=/opt/wayside/areas.txt
#
# This file is the control. An area not listed here is not built, whatever is
# in cities.json — that file says which areas *exist*, this one says which are
# worth the download and the disk.
#
# EVERY EUROPEAN CAPITAL AND EVERY EUROPEAN CITY OF A MILLION OR MORE
# RESIDENTS — the same rule and the same set apps/air publishes its wash for,
# so a reader who opens both layers over the same place is looking at the same
# city rather than two different ideas of where one ends. See
# apps/air/README.md for how the set was chosen and boundaries.geojson for
# where each outline came from; extra-cities.json carries the names for the
# cities in this list with no page of their own in the app.
#
# Each of these is clipped to its own administrative boundary plus ten
# kilometres — see boundaries.geojson and NOISE_BOUNDARY_BUFFER — rather than
# to a circle on its centre. Sixty-four areas across forty-seven countries is
# NOISE_EXTRACTS in docker-compose.prod.yml, and it is tens of gigabytes: see
# that file for why the download is cached rather than repeated.
