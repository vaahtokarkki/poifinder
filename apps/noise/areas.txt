# Which areas get noise tiles.
#
#   docker compose -f docker-compose.prod.yml run --rm builder \
#     build-noise-tiles --areas=/opt/wayside/areas.txt
#
# This file is the control. An area not listed here is not built, whatever is
# in cities.json — that file says which areas *exist*, this one says which are
# worth the download and the disk.
#
# EVERY EUROPEAN CAPITAL AND EVERY EUROPEAN CITY OF A MILLION OR MORE
# RESIDENTS, the same set apps/air publishes its wash for, PLUS every city
# cities.json carries a prerendered page for — the app should not send a
# reader to a city page with no noise layer under it. See apps/air/README.md
# for how the European set was chosen and boundaries.geojson for where each
# outline came from; extra-cities.json carries the names for the European
# cities in this list with no page of their own in the app.
#
# Each of these is clipped to its own administrative boundary plus ten
# kilometres — see boundaries.geojson and NOISE_BOUNDARY_BUFFER — where one
# has been fetched, and to a circle on its centre otherwise. NOISE_EXTRACTS in
# docker-compose.prod.yml has one Geofabrik extract per country named here,
# and it is tens of gigabytes: see that file for why the download is cached
# rather than repeated.
