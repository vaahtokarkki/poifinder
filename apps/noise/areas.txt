# Which areas get noise tiles, and the extracts they need.
#
#   docker compose -f docker-compose.prod.yml run --rm builder \\
#     build-noise-tiles --areas=/opt/wayside/areas.txt
#
# This file is the control. An area not listed here is not built, whatever is
# in cities.json — that file says which areas *exist*, this one says which are
# worth the download and the disk.
#
# HOW THE LIST WAS CHOSEN
#
# Two filters, and neither is the SEO tiering in cities.ts, because that ranks
# what earns search impressions and this is a map feature.
#
# First, countries. Every country with any real usage in Matomo over the last
# 90 days — a reader who opened a city page there. That is 25 countries, and it
# is a thin signal on a young site: 93 visits in all. It is still a better
# ordering than a guess, and Berlin, which this model was built and validated
# against, drew one of those 93.
#
# Second, size within those countries: at least 4,000 points in the nine
# categories the noise row renders for (see NOISE_WORTH_KNOWING in
# NoiseSection.tsx), or any usage at all. Counted from data/poi.
#
# THE COST IS THE EXTRACT, NOT THE CITY
#
# Germany is one 4.5 GB download and seven cities. Czechia is one 0.9 GB
# download and one. Both are worth having; only one of them is cheap. The list
# is grouped by extract for that reason, and the totals below are what a full
# run downloads.
