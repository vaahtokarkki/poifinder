# Geofabrik extracts covering every area in areas.txt: every European capital
# and every European city of a million or more residents, the same set
# apps/air publishes its wash for. This is what NOISE_EXTRACTS in
# docker-compose.prod.yml holds; kept here too so a local build can use the
# same list without retyping it.
#
# Used as:
#
#   NOISE_EXTRACTS="$(grep -v '^#' europe.txt | tr '\n' ' ')"
#
# One extract per country rather than europe-latest.osm.pbf, for the same
# reason apps/overpass assembles a region at a time: the continent file is a
# single download of 30 GB and more, and osmium reading it costs the whole of
# it on the disk, where these are the same places one country at a time with
# nothing ever held but the largest of them.
#
# Tens of gigabytes total, cached in NOISE_CACHE_DIR after the first run — see
# docker-compose.prod.yml for why storage rather than a repeat download is the
# right thing to spend on this.
#
# Armenia is the one entry not under europe/ — Geofabrik files it under asia/,
# and Yerevan is still on the list.
